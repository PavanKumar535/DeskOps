
# DeskOps - Team Work Distribution

## Team Roles

The team has agreed on the following primary roles and responsibilities for Phase 1.

### Paavan - Primary Role: Engineer B

- Ticket lifecycle and status transitions
- Ticket event history
- Internal and public comments
- Client-specific business rule
- Database schema and ticket-related APIs

### Pavan - Primary Role: Engineer D

- Docker and Docker Compose
- GitHub Actions and CI/CD
- Staging deployment
- Application integration
- Monitoring and deployment support

## Shared Responsibilities

Both team members will share the responsibilities of Engineer A and Engineer C equally.

This includes:
- Organisation and tenant-related work
- Attachments
- Inbound email integration
- Real-time updates
- Authentication and other required integrations
